# 图标与 Logo 设计技能

本技能适用于一切需要简洁符号化表达的图形，并在《SVG 设计规范》的硬性限制下工作（根元素必须带 viewBox、禁用 script/foreignObject/image、不得引用外部 URL 与字体等）。

## 一、适用范围

- 图标（按钮/工具栏图标、应用图标、界面图标）。
- Logo、标识、徽章、品牌符号。
- 任何要求"简洁、符号化、强识别性"的矢量图形。

## 二、设计流程

1. **先明确前提**：用途（UI 图标 / 品牌 Logo / 徽章）、尺寸比例（方 / 圆 / 宽）、风格方向（线性 / 面性 / 扁平 / 渐变 / 拟物）、颜色限制（单色 / 双色 / 品牌色）。
2. **收敛核心符号**：用一个可记忆的形状或组合表达主题，例如盾 = 安全、闪电 = 速度、叶子 = 自然；一个图形只承载一个核心符号。
3. **网格化设计**：以 24×24 或 32×32 为逻辑网格，关键点对齐网格线；viewBox 使用 `0 0 24 24` 或 `0 0 32 32`，保证小尺寸下缩放清晰。
4. **统一描边**：线性风格时 stroke-width 全图一致（如 1.5–2），端点与转角圆角处理（stroke-linecap、stroke-linejoin 设为 "round"）。

## 三、造型原则

- **极简**：能删则删，一个图标只有一个焦点；负空间与正形同等重要，删掉任何一笔都不完整的程度才算到位。
- **视觉平衡**：几何中心对齐，圆与方组合时做必要的光学微调；描边粗细与形状尺度匹配，大图形用相对粗的描边。
- **可识别性优先于装饰**：小尺寸下仍可辨认，避免过细线条、过多细节与高频细节堆叠。
- **颜色**：单色为主（currentColor 不可用时用固定色），或双色主次分明；渐变克制，仅在需要层次时使用。

## 四、常见类型规范

- **线性图标**：以描边为主，圆角端点，镂空负空间表达；**面性图标**：实心填充，圆角形状，轮廓饱满。
- **Logo 类**：图形优先于文字（无字体保证时文字是弱项）；确需图文结合时用 `<text>`（默认字体），控制字间距与图形协调，字号宁大勿小。
- **徽章**：同心圆、盾形或圆角矩形外框 + 内部符号 + 可选细描边；内部符号与外框之间留出均匀边距。

## 五、检查清单

生成前逐项检查：

- 关键点是否对齐逻辑网格。
- 描边宽度、圆角、线帽是否全图统一。
- 正负空间是否平衡、焦点是否唯一。
- 小尺寸（16–24px 级别）下是否仍可辨认。
- 全部内容是否落在 viewBox 内、无溢出。
- 颜色是否协调、饱和度是否受控。
