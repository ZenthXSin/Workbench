# 构图与细节技能

本技能面向复杂、精细的 SVG 矢量图形，在《SVG 设计规范》的硬性限制下工作（根元素必须带 viewBox、禁用 script/foreignObject/image、不得引用外部 URL 与字体等）。规范负责"画得合法"，本技能负责"画得有序、画得精致"。

## 一、适用范围

满足下列任意一条时加载本技能：

- 复杂图形：角色、机械、建筑、场景类多部件组合图形。
- 精细图形：产品图、数据图表、需要细腻质感与层次的表现。
- 画面元素数量多、结构关系复杂，需要清晰结构时。
- 需要精致细节（光影、纹理、高光）而非极简符号时。

若目标只是单个图标或 Logo，应优先加载《图标与 Logo 设计》，本技能与其互补使用。

## 二、分层结构

- **图层顺序**：`<defs>`（渐变、符号、pattern）→ 背景 → 主体底层 → 主体中层 → 前景 → 高光/装饰，按此顺序书写元素；后面的元素自然盖住前面的，保证遮挡关系正确。
- **组件分组**：每个逻辑部件一个独立的 `<g id="...">`（如 `g id="body"`、`g id="arm-left"`），便于定位、修改与复用；组内继续细分时用有意义的嵌套 id。
- **变换组合**：移动、缩放、旋转一律用 `<g transform="translate(x y) scale(s) rotate(a)">` 表达，不要重写坐标；同一部件只定义一次几何，通过 transform 摆放多份。
- **复用优先**：重复出现的部件（轮子、叶片、按钮）放进 `<defs>` 的 `<symbol>`，用 `<use href="#id">` 实例化；同一渐变、pattern 只在 `<defs>` 定义一次。

## 三、视觉焦点

- **一张图一个焦点**：画面围绕唯一的视觉中心组织；其他元素的功能是衬托焦点，而非与它争抢。
- **聚焦手段**：对比度、细节量、饱和度三项向焦点集中——焦点处明暗对比最强、细节最多、色彩最饱和；非焦点区域相应减弱。
- **细节密度梯度**：焦点处细节密度高，向四周逐渐稀疏；避免全图同等细节——处处精细等于没有重点。

## 四、边缘与对齐

- **数学对齐**：关键边缘对齐网格或整数坐标；对称元素使用精确对称的坐标值（如圆心对称、镜像相同的路径），不要目测手摆。
- **曲线平滑**：路径控制点对称分布、相邻曲线切向连续，让过渡自然；除刻意风格（折纸、低多边形）外避免突兀折角。
- **描边重叠**：描边相交处使用 `stroke-linejoin="round"`（或按风格统一 miter/round）避免尖刺；重叠线条需要区分层次时，用独立外描边（细描边 + 底色描边隔离）而不是靠滤镜。

## 五、光影细节

- **统一光源**：全图主光源方向一致（例如统一左上 45° 入射），所有部件的亮面、暗面朝向同一光源，不得各自为政。
- **体积三层**：每个体积感部件至少分亮面、暗面、明暗交界线三层表达，用渐变（linearGradient/radialGradient）或相邻色块过渡。
- **高光**：用细线或小形状表达，fill 为白色或近白色、低不透明度（如 0.3–0.6），沿受光边缘放置。
- **投影**：主体下方放置偏移形状（深色、低不透明度，如黑色 0.15–0.3），不依赖 filter 实现；多主体时投影方向一致。

## 六、细节节奏

- **分区密度**：把画面分成焦点区、过渡区、远处三档细节密度——焦点区最密、过渡区中等、远处简洁（可只留剪影）。
- **重复元素**：重复的形状用 `<use>` 或 `<symbol>` 复用，既保证一致性又节省代码；需要变化时（大小、角度）在 use 外层叠加 transform。
- **纹理克制**：纹理用 `<pattern>` 小图案或重复小形状实现，只在需要质感的局部使用，密度与对比度压低，避免干扰主体。

## 七、检查清单

生成前逐项检查：

- 分层是否清晰：defs → 背景 → 主体底层 → 中层 → 前景 → 高光，顺序与遮挡关系正确。
- 焦点是否唯一：对比度、细节量、饱和度是否全部向同一焦点集中。
- 边缘是否平滑对齐：关键坐标对齐网格，曲线切向连续，描边连接处无尖刺。
- 光影是否统一：光源方向一致，体积三层齐全，高光与投影方向匹配。
- 细节是否有节奏：密度由焦点向外渐疏，重复元素已用 use/symbol 复用。
- 完整性：全部内容落在 viewBox 之内、无溢出，无 script 与外部引用，仅使用运行时支持的能力。
