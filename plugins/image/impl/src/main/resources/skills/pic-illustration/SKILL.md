# 插画风格技能

本技能适用于一切需要风格化表现的 SVG 插画，并在《SVG 设计规范》的硬性限制下工作（根元素必须带 viewBox、禁用 script/foreignObject/image、不得引用外部 URL 与字体等）。

## 一、适用范围

- 角色、动物、场景、装饰图案等插画类图形。
- 需要风格化、有辨识度而非写实表现的图形；用户说"插画""可爱""扁平""卡通""复古"等风格词时加载本技能。
- 生成结果将由 generate_svg 工具以 SVG 形式产出。

## 二、确立风格方向

动手前先选定一个风格方向，全程只执行它，**绝不混搭**：

- **扁平插画**：纯色块为主，无渐变或极少渐变，圆角统一，比例夸张。
- **渐变插画**：柔和渐变背景，光晕氛围，用明暗表达体积感。
- **线条插画**：粗细一致的描边勾勒轮廓，留白为主，线性叙事。
- **几何插画**：由基础形状（圆、三角、矩形）构成，强调对称或网格秩序。
- **复古/像素风**：有限色板（如 4–6 色），带轮廓线，造型硬朗。

## 三、形状语言

- **统一圆角与描边**：全图圆角半径一致（如全部 12 或全部 24），描边粗细一致，线帽线角统一。
- **比例夸张**：大头小身、大眼小嘴等风格化比例优先，避免写实解剖。
- **形状简化**：用最少的路径表达对象，能圆则圆、能直则直，不堆叠多余细节。

## 四、构图节奏

- **主体占比**：主体占画布 1/3 以上，留白有意识，不平均分配空间。
- **构图方式**：三分法、中心构图或对角构图，先定构图再摆元素。
- **层次**：前景 / 中景 / 背景分明，用大小和明度区分（远小近大、远淡近浓）。
- **节奏**：元素按韵律重复形成秩序，再用一处突变（异色、异形、异大）制造焦点。

## 五、场景与氛围

- **背景**：纯色、渐变、图案或几何装饰，只用来衬托主体，不与主体抢眼。
- **光与色**：暖色=舒适、冷色=安静、高对比=紧张，氛围由整体配色决定。
- **装饰克制**：装饰元素只放服务氛围的 2–3 个，多余的一律删掉。

## 六、风格化技巧

- **数学坐标**：用精确坐标控制形状的比例与对齐，圆角、圆心、偏移都算清再写。
- **阴影**：扁平风格用色块（深一档的纯色偏移）表达；体积风格用渐变过渡；不依赖 filter 实现。
- **辨识度**：高光点（小白点、亮色小块）、轮廓线（统一描边）增强角色与图形的辨识度。
- **能力边界**：只使用基础形状、路径与渐变；不依赖 filter、script、外部资源与字体。

## 七、检查清单

生成前逐项检查：

- 风格方向统一，未混搭多种风格。
- 比例夸张有辨识度，非写实堆细节。
- 前景 / 中景 / 背景层次分明。
- 装饰元素克制（≤3 个）且服务氛围。
- 全部内容完整落在 viewBox 内、无溢出。
