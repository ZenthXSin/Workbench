# 配色理论技能

本技能用于确定 SVG 图形的完整配色方案，与《SVG 设计规范》配合使用：规范负责语法边界与结构，本技能负责颜色选择、配色关系与明暗层次。所有颜色以 hex 色值落笔，渐变用 linearGradient / radialGradient 表达。

## 一、适用范围

满足下列任意一条，就应加载本技能：

- 任何需要确定颜色方案的 SVG：插画、图标、Logo、数据可视化（图表、仪表盘、信息图）。
- 用户只给出含糊的颜色诉求（"好看点""高级感""科技风"），需要自行定调时。
- 画面已有配色但层次平淡、颜色发脏、对比不足，需要提升色彩层次时。

## 二、基础配色模型

1. **色相环六种关系**，先选一种关系再定具体色值：

   - **单色**（同一色相不同明度/饱和度）：最安全，层次统一，适合大面积背景与正式场合。
   - **邻近色**（色相环上相邻 30°–60°，如蓝与青、橙与黄）：和谐自然，适合插画与内容型画面。
   - **互补色**（色相环上相对 180°，如蓝与橙、红与绿）：对比强烈，适合突出主视觉与数据对比，需控制双方面积与饱和度，避免刺眼。
   - **分裂互补**（互补色一侧的色相改为其两个邻近色，如主色蓝 + 黄橙/红橙）：比互补色柔和，对比仍清晰，推荐用于需要醒目又不失高级感的画面。
   - **三角色**（色相环均分 120°，如红/黄/蓝）：活泼均衡，适合儿童向、庆典类图形，使用时降低饱和度。
   - **四角色**（色相环均分 90°，两组互补）：丰富多变但最难驾驭，只在需要多彩画面时使用，且始终保持一组色占主导。

2. **面积比例确立主次**：每张图必须确立一个**主色**（约占画面 60% 面积，用于背景与大形）、一个**辅助色**（约 25%，用于次要结构与内容元素）、一个**点缀色**（5–10%，用于焦点、高光与关键细节）。点缀色是唯一可以与主色形成互补关系的颜色，用在小面积上即可制造视觉焦点而不破坏整体和谐。

## 三、HSL 思维

- **用 HSL（色相 / 饱和度 / 明度）三个通道思考，不要凭裸色值拼凑**。落笔时把 HSL 换算为 hex（如 hsl(215, 60%, 50%) ≈ #3366CC）。
- 定色时先定**色相**（决定色调倾向），再定**饱和度**（大面积低饱和、点缀可高饱和），最后定**明度**（决定轻重与层次）。
- **固定色相、微调明度/饱和度**是生成和谐层次的核心手法：同一色相下取 3–5 个明度档位（如 35% / 50% / 65% / 80%），天然协调、不会花。
- 饱和度受控：大面积颜色饱和度尽量不超过 60–70%，避免全图高饱和刺眼。

## 四、渐变与体积

- **体积渐变**：同色相的明度递进——高光侧用高明度档，阴影侧用低明度档，两个 stop 之间只有明度差。**避免跨色相渐变**（如直接从蓝渐变到绿），会产生发脏的中间色。
- **环境光渐变**：需要色彩倾向时，让主色向**邻近色相**方向偏移（如蓝色物体受暖光时向紫色轻微偏移），偏移幅度控制在色相环 30° 以内。
- **光源方向**：渐变方向必须与光源一致。默认左上光源：高光在左上、阴影在右下，linearGradient 用 gradientTransform 旋转对齐光源角度；球体等圆形物体用 radialGradient，焦点偏向光源侧。
- 渐变 stop 全部使用 hex 色值，定义在 `<defs>` 中通过 `#` 引用，与运行时能力保持一致。

## 五、阴影与高光

- **阴影**：主色 + 明度降低 20–30%，**保持色相不变**；需要冷阴影时可把色相向蓝色方向微调（约 10–20°），形成通透感。**绝不用纯黑**（#000000）做阴影——会脏、会闷。
- **高光**：主色 + 明度提高 15–25%，或同明度下降低饱和度；**绝不用纯白**（#FFFFFF）做高光——会让体积感发平、发灰。
- 阴影与高光同时存在时，中间必须保留主色本体色阶过渡，形成完整体积感，而不是两段硬切。

## 六、常见配色方案参考

以下组合可直接套用（主 / 辅 / 点）：

1. **深蓝 + 青 + 白（科技感）**：深蓝 #0B3D91（主，大面积底）、青 #22B8CF（辅，结构与强调块）、白 #F5F7FA（点，文字与高光）。用于科技、数据、工具类画面。
2. **暖橙 + 棕 + 米（复古）**：米 #F3E9DC（主，背景）、棕 #6B4226（辅，主体大形）、暖橙 #E07A3F（点，焦点细节）。用于复古、人文、手作风。
3. **森林绿 + 金（自然高端）**：深绿 #2F5233（主）、浅绿 #6B8F5E（辅，明暗层次用同色相渐变）、金 #C9A227（点，点缀与高光）。用于自然、生态、高端品牌。
4. **暗紫 + 粉（梦幻）**：暗紫 #4A1E6E（主，深色底）、中紫 #7C4DA8（辅）、粉 #F4A7C3（点，光效与焦点）。用于幻想、星空、女性向插画。

## 七、检查清单

生成前逐项检查：

- 是否确立了主 / 辅 / 点三色，面积比例接近 60% / 25% / 5–10%。
- 所有用色是否围绕一个明确的色相关系（单色 / 邻近 / 互补 / 分裂互补 / 三角 / 四角），无随意混搭。
- 前景与背景、文字与底色对比是否可辨（深色底配浅色文字，浅色底配深色文字）。
- 大面积颜色是否低饱和、无高饱和刺眼色块。
- 渐变是否同色相明度递进、方向与光源一致、无跨色相脏色。
- 阴影是否非纯黑、高光是否非纯白，明暗是否保留本体色过渡。
- 点缀色是否只出现在小面积焦点处，而非铺满全图。
